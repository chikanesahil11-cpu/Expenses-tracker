**Take control of your expenses. Understand your spending. Manage your money better.**

Ledgerly is a web-based personal expense tracking application developed using Python and Django. It aims to make recording and managing everyday expenses simple and organized.

---

## 📌 Project Overview

Managing daily expenses can become difficult without a proper record. Ledgerly aims to solve this problem by providing a centralized application where users can maintain and review their expense records.

This project was developed to apply practical concepts of Python, Django, database management and web application development.

## ✨ Key Features

- **Expense Management:** Maintain personal expense records.
- **Expense Tracking:** Keep track of recorded spending.
- **Organized Records:** Access expense information in one place.
- **Web-Based Application:** Use the application through a browser.

## ⚙️ Installation & Setup

Follow these steps to run Ledgerly locally.

**1. Clone the repository**

```bash
git clone https://github.com/chikanesahil11-cpu/Expenses-tracker.git
```

**2. Open the project directory**

```bash
cd Expenses-tracker
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the environment (Windows)**

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Apply database migrations**

```bash
python manage.py migrate
```

**7. Start the development server**

```bash
python manage.py runserver
```

Open your browser:

`http://127.0.0.1:8000/`
